# PHP Study Notes

These are my personal study notes from learning PHP and using it to build command-line and server-side applications. I am collecting the language fundamentals, web request patterns, database access, and practical application ideas I want to understand and revisit while studying and working.

## About these notes

The chapters begin with the PHP runtime and command line, then move through types, functions, arrays, object-oriented code, Composer, HTTP, sessions, database access, files, testing, and production practices. Each chapter explains why a concept matters, includes focused PHP examples, and ends with review questions.

Examples use PHP and its standard library unless a chapter introduces a tool such as Composer, PHPUnit, or PDO. PHP versions, extensions, and server configuration can differ, so check the official documentation for the environment you use.

## Core topics

- Run PHP from the command line and understand its web request lifecycle
- Work with values, type declarations, functions, arrays, and strings
- Organize code with classes, interfaces, namespaces, and Composer
- Handle HTTP requests, forms, sessions, cookies, and JSON responses
- Validate input and protect forms against cross-site request forgery
- Query databases with PDO, bound parameters, and transactions
- Read files and handle uploads safely
- Test behavior with PHPUnit
- Apply security, error handling, and deployment practices
- Build a small JSON service from the core language features

## How I use these notes

I run short examples with the PHP CLI, then try them in a local development server when a request or form is involved. I keep credentials out of source files, use disposable practice data, and use the review questions to check that I can explain each concept in my own words.
